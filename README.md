🚀 Cattle Breed Detection System

AI-powered web application to detect cattle breeds using deep learning for smart agriculture.

📌 Overview

This project uses Deep Learning (CNN) to classify cattle breeds from images.
Users can upload an image or provide an image URL to instantly detect the breed.

✨ Features
🐄 Cattle breed detection using AI
📷 Upload image or paste image URL
⚡ Real-time prediction
🌐 Interactive web app using Streamlit
📊 Clean and user-friendly UI
🛠️ Tech Stack
Frontend: Streamlit
Backend: Python
ML Model: TensorFlow / Keras
Libraries: NumPy, Pillow, Matplotlib
